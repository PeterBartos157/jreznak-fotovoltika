# Green Energy Solutions

Moderná webová prezentácia pre spoločnosť zameranú na obnoviteľné zdroje energie, fotovoltické systémy, batériové úložiská a energetické riešenia.

## 🚀 Použité technológie

- Vue 3
- Quasar Framework
- TypeScript
- Vue Router
- EmailJS
- CSS (Scoped Styles)

---

## 📋 Funkcionality

### Domovská stránka
- Hero sekcia s výzvou k akcii
- Predstavenie spoločnosti
- Prehľad služieb
- Výhody spolupráce
- Referencie zákazníkov
- FAQ sekcia
- CTA bannery

### Spoločnosť
- Predstavenie firmy
- Vízia a misia
- Skúsenosti spoločnosti
- Predstavenie tímu

### Služby
- Inštalácia fotovoltických systémov
- Batériové úložiská
- Servis a údržba
- Solárne oplotenie

### Projekty
- Galéria realizovaných projektov
- Informácie o zákazníkovi
- Typ realizácie
- Lokalita projektu

### Kontakt
- Kontaktný formulár
